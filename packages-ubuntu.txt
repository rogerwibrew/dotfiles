# NOTES ON MISSING/ALTERNATIVE PACKAGES
# ============================================================================

# The following packages from Arch need special handling on Ubuntu:

# 1. lazygit - May not be in Ubuntu repos
#    Install via: snap install lazygit OR build from source
#    Alternative: use regular git with zsh aliases

# 2. lazydocker - Not in Ubuntu repos
#    Install via: go install github.com/jesseduffield/lazydocker@latest
#    Or: curl https://raw.githubusercontent.com/jesseduffield/lazydocker/master/scripts/install_update_linux.sh | bash

# 3. yazi - Terminal file manager (not in Ubuntu repos)
#    Install via: cargo install --locked yazi-fm yazi-cli
#    Requires: cargo (listed above)

# 4. eza - Modern ls replacement (not in Ubuntu repos)
#    Install via: cargo install eza
#    Alternative: use 'exa' (older version) or regular 'ls'

# 5. cliphist - Clipboard history manager
#    Build from source: https://github.com/sentriz/cliphist
#    Requires: go install go.senan.xyz/cliphist@latest

# 6. pamixer - PulseAudio/PipeWire mixer CLI
#    May need to build from source or use alternative (pactl, wpctl)

# 7. hyprpicker - Color picker (Hyprland-specific)
#    No direct replacement needed (Hyprland → Sway migration)
#    Alternative: use grim + slurp for screenshots, extract color manually

# 8. Material Design Icons Desktop font
#    Not easily available on Ubuntu
#    May need to download manually from: https://github.com/Templarian/MaterialDesign-Font
#    Or use Font Awesome icons as fallback

# 9. Claude Code - Install via official script
#    curl -fsSL https://claude.ai/install.sh | bash

# 10. nvm (Node Version Manager) - Install via official script
#     curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# 11. Epson printer driver (AUR: epson-inkjet-printer-escpr2)
#     Check Epson website for Ubuntu .deb package
#     Or use generic CUPS drivers
